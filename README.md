# StudentManagement.API

ASP.NET Core Web API for managing students, courses and enrollments.

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- REST API
- Postman
- SQL

## QA & Testing

This project includes:

- Manual test cases
- API testing with Postman
- Test execution reports
- Bug reports
- SQL data validation

## QA Documentation

The `QA` folder contains:

- `Test-Cases.xlsx` — Functional test cases
- `Postman-Collection.json` — API test collection
- `SQL-Validation.sql` — SQL validation queries
- `Test-Results/` — Test execution reports
- `Bug-Reports/` — Bug reports

## API Operations

### Students

- GET all students
- GET student by ID
- POST student
- PUT student
- DELETE student

### Courses

- GET all courses
- GET course by ID
- POST course
- PUT course
- DELETE course

### Teachers

-  GET all teachers
- GET teacher by ID
- GET teacher by teachercode
- POST teacher
- PUT teacher
- DELETE teacher

## Testing Tools

Postman was used for API testing and SQL Server was used for database validation.
