# BUG-001

## Title

GET teacher returns 500 Internal Server Error

## Endpoint

GET /api/Teachers/{id}

## Severity

High

## Priority

High

## Status

Fixed

---

## Preconditions

- API is running
- Database is available
- Course exists

---

## Steps to Reproduce

1. Open Postman
2. Select GET request
3. Enter `/api/Teachers/{id}`
4. Send the request
5. Observe the response

---

## Expected Result

200 OK with a valid JSON response.

---

## Actual Result

500 Internal Server Error.

---

## Error Message

A possible object cycle was detected.

---

## Root Cause

Circular reference between related entities.

Teacher → Courses → Teacher

---

## Fix

Use DTOs and return only the required properties.

---

After applying the fix:

200 OK
